Escalators

An Escalator transport is a fixed-time connection between exactly two topo-map instances.

Common station, access, ride-policy, transfer, and output rules are defined in Cross-Map Transportation.

Declaration

transport AtriumEscalator is Escalator {
  let params = {
    time = 18.0
  }

  let displayName = "Atrium escalator"

  station Lower at MallLevel2::atrium_escalator_landing {}
  station Upper at MallLevel3::atrium_escalator_landing {}
}

Fixed Travel Time

params.time is the complete travel time in seconds between the two stations.

  • time is required.
  • It may be an Int or Float.
  • It must be finite and greater than zero.
  • No additional waiting, velocity, acceleration, or dwell-time calculation is applied.

Stations

An escalator must declare exactly two stations, and the stations must belong to two distinct topo-map instances. Station records may be empty because escalators do not require location, departureRate, or directSegmentIndex.

The declaration order is not a physical elevation or direction declaration.

Operating Direction

An escalator is currently modeled as a fixed-time connection that can be traversed in either direction. This model is suitable for a bidirectional escalator service, such as a paired up-and-down installation represented as one transport.

A map author cannot currently declare that a particular escalator operates only upward, only downward, or reverses direction according to an operating schedule.

Station access requirements and out-of-order describe authorization or availability. They do not describe the escalator's ordinary operating direction.

Station Availability

Escalators support unscoped, arrival-only, and departure-only station requirements, uncertain access, and out-of-order in the same way as elevators:

station Upper at MallLevel3::atrium_escalator_landing {}
  requires MallOpen on Arrive

See Station Access.

Route Output

An escalator ride is returned as a Transport segment with the configured fixed travel time.

Invalid Escalator Declarations

  • A missing or non-numeric params.time fails compilation.
  • A non-finite, zero, or negative time fails compilation.
  • Fewer or more than two stations fail compilation.
  • Two stations belonging to the same topo-map instance fail compilation.
  • An unknown station map or node fails compilation.
