Map Selection and Reuse

A topo-map source defines local floor topology. It becomes part of a building only when selected as a submap by building-includes. A reusable source may produce multiple named instances, but each instance represents one particular floor.

Where Submaps Are Declared

submap is a whole-building composition entry, not a declaration nested inside a topo map. Direct selection, source resolution, reusable using instances, ordering, and management-domain attachment are documented in Whole-Building Composition.

No Parent-Map Hierarchy

Current TopoScript does not define parent and child topo maps. Included map instances are sibling navigation graphs in the compiled building.

The root source is a shared declaration environment, not a parent map. building-includes is the project manifest, not a navigable map. Neither contains the physical topology of its included floors.

Cross-Map Connections

An atomic path cannot connect nodes from different topo maps. Cross-map movement is declared by a transport whose stations refer to nodes in the participating floor maps.
